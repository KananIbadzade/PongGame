# Pong Game (C++ + raylib)

Simple Pong clone built with C++17 and the raylib graphics library.

## Quick Start (macOS Apple Silicon)

```bash
brew install raylib        # install dependency once
git clone https://github.com/KananIbadzade/PongGame.git
cd pong_game/PongGame
make                       # builds ./pong using the Makefile
./pong                     # run the game
```
